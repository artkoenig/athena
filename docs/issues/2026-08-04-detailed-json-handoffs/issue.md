# Detaillierte JSON-Handoffs über Dateien generieren

## Problem
Die aktuellen JSON-Handoffs der Subagenten fallen extrem kurz aus (z. B. `{"technical_specification": "spec"}`). Dies liegt vermutlich daran, dass die Agenten versuchen, die JSON-Daten direkt als String im CLI-Befehl (`--json-data '{...}'`) zu übergeben. Um Escaping-Probleme und Längenbeschränkungen im Terminal zu vermeiden, generieren sie künstlich kurze Platzhalter-Texte. Die Handoffs müssen jedoch alle technischen Details, Architekturentscheidungen und Findings vollständig enthalten.

## Akzeptanzkriterien
- [x] In allen Agenten-Prompts (`agents/dispatcher.md`, `agents/implementer.md`, `agents/reviewer.md`, `agents/test-author.md`) wird die Anweisung zur Handoff-Generierung so geändert, dass das JSON **immer in eine temporäre Datei** (z. B. `handoff.json`) geschrieben werden soll.
- [x] Der CLI-Befehl in den Prompts wird von der direkten String-Übergabe auf die Dateipfad-Übergabe umgestellt (z. B. `python3 tools/handoff/generate.py --agent dispatcher --json-data handoff.json`).
- [x] In den Prompts wird explizit und unmissverständlich darauf hingewiesen, dass die JSON-Felder ausführlich und detailliert befüllt werden müssen (keine Platzhalter, vollständige Übernahme aller Research-Ergebnisse, Modul-Maps etc.).
- [x] Nach erfolgreicher Validierung durch `generate.py` sollen die Agenten angewiesen werden, die temporäre JSON-Datei wieder zu löschen.

## Handoff Dispatcher

### Technical Specification
The issue requires updating the agent prompts to ensure that the JSON handoffs generated by agents contain detailed and comprehensive information without being limited by terminal string size constraints or escaping issues. To achieve this, the prompts will be updated to instruct the agents to first write the JSON structure into a temporary file (`handoff.json`), pass the file path to the `generate.py` script via `--json-data`, and subsequently delete the temporary file after a successful handoff.

### Module Map
- `agents/dispatcher.md`: Updated handoff generation instructions to use a temporary file, request detailed JSON without placeholders, and delete the file after success.
- `agents/implementer.md`: Updated handoff generation instructions to use a temporary file, request detailed JSON without placeholders, and delete the file after success.
- `agents/reviewer.md`: Updated handoff generation instructions to use a temporary file, request detailed JSON without placeholders, and delete the file after success.
- `agents/test-author.md`: Updated handoff generation instructions to use a temporary file, request detailed JSON without placeholders, and delete the file after success.
- `tools/handoff/generate.py`: Already supports reading from file paths for `--json-data`. No modifications needed.
